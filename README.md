AI-Based Fake Image and Video Detection System

An AI-powered deep learning application that detects whether an uploaded image or video is REAL or AI-GENERATED.

The project is built using Python, TensorFlow, MobileNetV2, OpenCV, and Streamlit.

==================================================
FEATURES
==================================================

- AI Fake Image Detection
- AI Fake Video Detection
- User Login & Registration
- Detection History Dashboard
- PDF Report Generation
- Streamlit Web Interface
- SQLite Database Support

==================================================
TECHNOLOGIES USED
==================================================

- Python
- TensorFlow
- Keras
- MobileNetV2
- OpenCV
- Streamlit
- SQLite
- NumPy
- Pandas
- Pillow
- ReportLab
